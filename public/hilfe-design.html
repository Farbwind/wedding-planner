Design der Gästeseite

Die Startseite für eure Gäste lässt sich im Reiter Design ohne Code gestalten. Wer mehr will, schreibt im Pro-Modus eigenes CSS und HTML. Diese Seite beschreibt, woran ihr euch dabei halten könnt.

Einstieg

  1. Öffnet in der Verwaltung den Reiter Design und wählt eine Vorlage.
  2. Passt Farben, Schrift, Formen und Aufbau an. Alles landet zuerst in einem Entwurf, den nur ihr in der Vorschau seht.
  3. Im Bereich Pro-Modus tragt ihr CSS und HTML ein. Die Vorschau lädt nach jeder Änderung neu.
  4. Mit Veröffentlichen sehen eure Gäste die neue Fassung. Entwurf verwerfen geht zurück zur veröffentlichten Fassung.

Die Vorschau ist auch direkt erreichbar: /?entwurf=1 zeigt den Entwurf, aber nur, wenn ihr in der Verwaltung angemeldet seid.

Aufbau der Startseite

Die Startseite ist body.seite-start mit einem main. Darin stehen diese Abschnitte, jeder mit einer eigenen Klasse. Die Reihenfolge stellt der Designer über die CSS-Eigenschaft order ein, deshalb ist main ein Flex-Container in Spaltenrichtung.

body.seite-start
  header.kopf          Kopfzeile mit Menü
  main
    section.hero       Namen, Datum, Foto
    section.countdown  Zähler bis zur Hochzeit
    section.termine    Ablauf mit Datum, Ort, Kalenderlink
    section.buchen     Zu- oder Absage
    section.momente    Fotos und Geschichte von euch
    section.geschenk   Geschenkwünsche
    section.wissen     Gut zu wissen
  footer.fuss          Fußzeile

CSS-Variablen

Alle Farben, Schriften und Rundungen hängen an Variablen auf :root. Wer sie überschreibt, ändert die ganze Seite auf einmal. Die Werte setzt der Designer aus euren Einstellungen. Euer eigenes CSS gilt danach und gewinnt bei gleicher Spezifität.

Attribute am html-Element

Der Designer setzt Attribute, mit denen die Grundgestaltung Varianten umschaltet. Ihr könnt sie in eurem CSS als Selektor nutzen.

AttributWerte
data-herobogen, vollbild, geteilt, schlicht
data-knoepfepille, eckig
data-rundungeckig, weich, rund
data-ausLeerzeichen-getrennte Liste ausgeschalteter Effekte: siegel, lichtpunkte, konfetti
/* nur im geteilten Anfang größere Namen */
html[data-hero="geteilt"] .namen { font-size: clamp(3rem, 8vw, 6rem); }

Tipp: Öffnet die Vorschau, klickt mit der rechten Maustaste auf ein Element und wählt „Untersuchen“. So seht ihr Klassen und Variablen direkt.

Eigene Blöcke

Blöcke fügt der Designer ohne Code ein. Sie sind section.block.block-TYP mit einer Innenfläche .block-innen und stehen an der gewählten Stelle. Bis zu 12 Blöcke sind möglich.

TypKlassen im Inneren
texth2, .bl-text
zitat.bl-zitat mit footer für den Urheber
bild.bl-bild mit img
zweispaltig.bl-zwei mit Bild links und Text rechts
knopf.bl-text und a.knopf
trenner.bl-trenner
.block-zitat .bl-zitat { font-size: 1.8rem; font-style: italic; }
#block-b1abc .block-innen { background: var(--farbe-akzent-hell); }

Jeder Block hat eine eigene ID im Format block-…. Sie steht im Quelltext der Vorschau.

HTML-Bereiche

Im Pro-Modus gibt es zwei Bereiche: HTML oberhalb steht in der Startseite vor dem Anfang, HTML unterhalb nach den Abschnitten. Beide stehen in einem div mit der Klasse pro-oben bzw. pro-unten.

<div class="hinweisband">
  <p>Bitte denkt an wetterfeste Schuhe, die Feier geht in den Garten.</p>
</div>
<style>
  .hinweisband { background: var(--farbe-akzent); color: var(--farbe-auf-akzent); text-align: center; padding: 10px 16px; }
</style>

Bilder aus der Verwaltung liegen unter /bilder/<Name>.jpg. Ladet sie im Block „Bild“ hoch und übernehmt den Dateinamen aus dem Quelltext der Vorschau, wenn ihr sie im eigenen HTML verwenden wollt.

Was nicht geht

Aus Sicherheitsgründen und wegen des Datenschutzes gibt es harte Grenzen. Alles Folgende wird beim Speichern entfernt oder vom Browser blockiert.

  • Kein JavaScript: weder <script> noch Attribute wie onclick noch javascript:-Links.
  • Keine eingebetteten Fremdinhalte: iframe, object, embed, link, meta, base sind entfernt.
  • Keine eigenen Formulare: form, input, button, textarea und select fehlen im Pro-Modus. Die Zusage übernimmt das vorhandene Formular.
  • Keine fremden Quellen: in CSS sind @import und url(https://…) gesperrt. Schriften und Bilder müssen von dieser Seite kommen oder als data:image/… eingebettet sein. Das schützt eure Gäste vor Tracking durch Dritte.
  • Größe: CSS und beide HTML-Bereiche je höchstens 30.000 Zeichen.
  • Schriften: verfügbar sind die sechs Paarungen des Designers (Cormorant Garamond, Playfair Display, DM Serif Display, Fraunces, Pinyon Script, DM Sans, Hanken Grotesk). Weitere Schriften müssen als Datei auf dem Server liegen.

Beispiele

Namen größer und mit Abstand

.namen { font-size: clamp(3.4rem, 11vw, 7.5rem); letter-spacing: .01em; }

Alle Karten mit weichem Schatten statt Rahmen

.termin, .buchung, .geschenk .block-innen {
  border: 0;
  box-shadow: 0 18px 40px -26px rgba(0, 0, 0, .35);
}

Eigener Hintergrund für die Zusage

.buchen { background: linear-gradient(160deg, var(--farbe-tief), var(--farbe-akzent)); }

Dunkelgrün für Knöpfe, Gold bei Hover

:root { --farbe-akzent: #1f4d3a; }
.knopf:hover { background: var(--farbe-gold); color: #161616; }

Foto im Anfang als Hintergrundbild aus der Verwaltung

html[data-hero="vollbild"] .hero-bild img { object-position: 50% 30%; }

Tipps

  • Fangt mit einer Vorlage an und ändert wenig. Eine ruhige Seite wirkt festlicher als eine überladene.
  • Prüft die Vorschau auf Handy. Die meisten Gäste öffnen den Link auf dem Telefon.
  • Achtet auf Kontrast. Textfarbe und Hintergrund sollten sich deutlich unterscheiden, besonders in der Zusage.
  • Versucht es mit Variablen statt mit festen Farben, dann passt sich das Design an, wenn ihr später eine Vorlage wechselt.
  • Wenn etwas nicht aussieht wie gedacht: Pro-Modus-Felder leeren, Vorschau neu laden und Zeile für Zeile wieder einfügen.
